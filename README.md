# AFTERWEB LAB 🌀

## Experimental Digital Artifact Archive

Welcome to **Afterweb Lab**.

A collection of strange digital artifacts, recovered experiments, forgotten machines, and mysterious creations born somewhere between the old internet and the unknown.

This repository is an experimental space for building small interactive experiences that feel like they were discovered inside a forgotten corner of the web.

Some artifacts are created.
Some artifacts are recovered.

The difference is not always clear.

## 📡 About the Afterweb

The Afterweb is a fictional digital realm inspired by:

* forgotten websites
* early internet culture
* GeoCities-era creativity
* abandoned digital spaces
* glitch aesthetics
* strange archives
* machines that seem slightly alive

This is not a normal website collection.

It is an exploration of what happens when old digital spaces refuse to disappear.
